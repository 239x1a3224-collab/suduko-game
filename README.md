 🧩 Sudoku Game

A simple and interactive Sudoku game built using **HTML**, **CSS**, and **JavaScript**. This project allows users to solve a 9×9 Sudoku puzzle directly in the browser.


 📌 Project Overview

This Sudoku game displays a partially completed puzzle. Players fill in the empty cells with numbers from 1 to 9. The game provides options to:

- Check whether the entered solution is correct
- Reset the puzzle to its original state
- Start a new game (reloads the same puzzle)

This project is suitable for beginners who want to learn DOM manipulation, event handling, and CSS Grid.

---

 ✨ Features

- Interactive 9×9 Sudoku board
- Pre-filled cells are locked
- Accepts only numbers 1–9
- Check solution functionality
- Reset puzzle functionality
- New Game button
- Responsive and clean user interface
- Success and error messages



🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity
